Cài đặt

Tải từ Release,
cài trên Boox chỉ 5 bước.

Luôn tải file ở trang Release chính thức để đúng phiên bản và đủ file. Không copy code lẻ từ GitHub.

File cần tải

booxbook.koplugin.zip trong mục Assets của bản mới nhất

Mở trang Release
  1. 1

    Tải file từ Release

    Mở trang Release mới nhất, kéo tới Assets, tải booxbook.koplugin.zip. Kiểm tra tên file đúng, không đổi tên.

  2. 2

    Giải nén rồi copy

    Giải nén file zip sẽ được thư mục:

    booxbook.koplugin/

    Copy nguyên thư mục vào đây:

    /sdcard/koreader/plugins/booxbook.koplugin/

  3. 3

    Restart KOReader

    Tắt hẳn KOReader rồi mở lại để nạp plugin mới. Chỉ vuốt ra nền chưa đủ.

  4. 4

    Bật plugin

    Tools → More tools → Plugin management → BooxBook, gạt công tắc sang bật.

  5. 5

    Mở BooxBook

    Tools → BooxBook. Màn hình chính hiện phiên bản (v{{BOOXBOOK_VERSION}}) ngay dưới tiêu đề là thành công.

Cập nhật bản mới

Mỗi bản mới đều nằm ở trang Release kèm booxbook.koplugin.zip. Tải zip mới, giải nén đè vào thư mục plugin cũ — hoặc bấm icon thông tin trên màn hình chính → Cập nhật → Cài đặt → Cập nhật từ GitHub (cần Wi-Fi). Dữ liệu trong koreader/booxbook/ và cookie được giữ lại. Restart KOReader sau khi cài.

Kiểm tra nhanh

Vào Cài đặt → Kiểm tra cài đặt (cần Wi-Fi): plugin gọi example.com, ghi _selftest.html có chữ “Tiếng Việt” và thử xuất EPUB vào koreader/booxbook/.

Hướng dẫn

Cách dùng từng phần.

Chi tiết đầy đủ trong docs/usage.md.

Báo → chọn tới bài mới tải

  1. Báo → Báo Việt / Báo Nước Ngoài → đầu báo → danh mục: chỉ tải tiêu đề, chưa tải nội dung.
  2. Chạm tiêu đề: tải toàn văn và mở bằng KOReader; lỗi thì dùng tóm tắt RSS.
  3. Tin đã tải: đọc lại offline. Thêm RSS tùy chỉnh: dán URL http(s), nằm trong nhóm riêng.
  4. Số bài mỗi danh mục: chỉnh 1–20 tiêu đề hiển thị.

Truyện → tìm → tải khoảng chương

  1. Mở nguồn (DocLN, Wattpad, Sangtacviet, MeTruyenCV, TVTruyen, Truyện Full), tìm từ khóa hoặc dán URL truyện.
  2. Icon menu góc trái mục lục → Tải khoảng chương / Tải toàn bộ / Tạo EPUB từ chương đã tải. Hoặc Mở chương bất kỳ theo số thứ tự mục lục.
  3. Tải lại cùng khoảng tự bỏ qua chương còn file; index.json.bak cứu khi index chính hỏng.
  4. Sangtacviet tắt mặc định — lần đầu mở sẽ hỏi xác nhận. Cookie từng nguồn dán từ trình duyệt trong Cài đặt.

Truyện Tuổi Thơ → tải CBZ từng tập

  1. Vào Truyện → Truyện Tuổi Thơ, duyệt Mới cập nhật / Lượt xem / Truyện mới / Thịnh hành, hoặc tìm tên / dán URL bộ & tập.
  2. Icon menu mục lục → Tải khoảng tập / Tải toàn bộ tập. Mỗi tập một CBZ riêng.
  3. Chạm thông báo tiến độ để tạm dừng / hủy / tiếp tục. Chọn lại tập để tải tiếp trang thiếu.
  4. Đọc offline ở Thư viện → comics → truyentuoitho → tên bộ → tập.cbz.

EPUB giữ tên gốc, bìa và nguồn

  1. Bật Cài đặt → Lưu truyện thành EPUB (mặc định tắt, HTML là mặc định).
  2. Mỗi khoảng tải xong có chapters-<từ>-<đến>.epub kèm mục lục; chọn dòng (EPUB) để đọc.
  3. Giữ bản HTML khi lưu EPUB bật mặc định; tắt để chỉ giữ EPUB sau khi xuất thành công.
  4. Thư viện mở koreader/booxbook/: chạm để đọc, nhấn giữ để đổi tên / xóa / thêm bộ sưu tập.

Gửi sách từ điện thoại / máy tính

  1. Cùng mạng Wi-Fi, mở BooxBook → Gửi sách qua Wi-Fi, giữ màn hình nhận sách mở.
  2. Điện thoại: Quét QR bằng camera. Máy tính: gõ http://…:8080/ rồi nhập mã phiên 6 chữ số (giữ số 0 đầu).
  3. Chọn một hoặc nhiều sách → Gửi sách. File trùng tên bị từ chối; file dở bị xóa khi dừng phiên.
  4. Bấm Dừng nhận sách → mở Thư viện → received để đọc. Chỉ dùng mạng tin cậy (HTTP).

Công tắc đáng chú ý

  • Cookie từng nguồn: dán session, không in ra log
  • Nội dung 18+: tắt mặc định · Ảnh minh họa: bật
  • Lưu EPUB: tắt · Giữ HTML khi EPUB: bật
  • Tự xóa HTML báo sau khi đọc xong: tắt
  • Ảnh bìa trần 50 MB + mục dọn ảnh thừa

Hỏi đáp

Những câu hỏi chung.

Có. BooxBook mã nguồn mở giấy phép AGPL-3.0-or-later, không tài khoản, không quảng cáo.

Mọi thiết bị chạy KOReader (Onyx Boox Android, Kindle, Kobo…). Một số tính năng ghi chú “chưa xác nhận trên máy thật” — hãy chạy Kiểm tra cài đặt sau khi cài.

Thường do chương khóa/VIP, captcha/rate-limit (HTTP 403/429) hoặc mất mạng. Plugin dừng lượt tải và giữ file đã lưu — thử lại sau, kiểm tra cookie, đồng hồ thiết bị và Wi-Fi.

LuaJIT, không thêm native library. Chạy luajit tests/run.lua. Rà RSS thật: pwsh -File scripts/news-feeds-live.ps1 -All. Xem quy ước và kiến trúc.
